# 红色警戒：重燃 — 垂直切片制作细案 v0.1

> 配套主文档：`红色警戒：重燃 — 详细游戏设计方案 v2.0.md`  
> 目标：将主文档中的 P0/P1 转为可配置、可测试、可验收的原型任务  
> 原型阵营：同盟联军、赤潮军团  
> 原型地图：第一张 1v1 灰盒地图“裂谷前线”  
> 数值状态：V0 灰盒基线，仅用于首轮测试

---

## 1. 本细案的边界

### 1.1 本轮要证明的问题

1. 采矿、扩张、电力和生产能否形成有意义的开局取舍。
2. 同盟机动与赤潮重甲是否在不依赖最终美术的情况下已经可辨。
3. 主战、反甲、防空、炮兵和高级单位能否形成混编，而非单一兵种最优。
4. 时空机动与装甲突击两个专精是否创造新决策，并且有明确反制。
5. 超时空传送和铁幕能否形成有预警、有反制的后期高光。
6. OpenRA 原型能否稳定完成完整 1v1，并生成一致回放。

### 1.2 本轮不证明的问题

- 不证明三阵营已经平衡。
- 不证明首发约 20 单位/阵营的完整军械库合理。
- 不验证随机动态事件、海战、合作守线和完整战役。
- 不验证千单位、回滚网络或最终画面品质。
- 不用本轮小样本结果直接决定商业首发平衡。

### 1.3 原型完成定义

垂直切片不是“功能都能演示”，而是：

- 两名玩家可从标准开局完整打到胜负结算。
- 经济、科技、专精和超级武器均参与真实对局。
- 同场输入能够生成一致回放。
- 至少存在快攻、双矿均衡、单基地科技三条可完成路线。
- 玩家能通过界面理解断电、技能预警和单位受阻原因。
- 所有关键规则有自动化或人工可重复的验收用例。

## 2. 统一数值口径

### 2.1 单位与武器字段

| 字段 | 含义 |
|---|---|
| 资金 | 生产时扣除的货币 |
| 时间 | 电力正常、无加成时的生产秒数 |
| 生命 | 基础最大生命值 |
| 速度 | 灰盒地图上的逻辑格/秒，最终需按实际引擎换算 |
| 射程 | 最大攻击距离，逻辑格 |
| 伤害/间隔 | 单轮基础伤害与两次攻击之间的秒数 |
| 指挥点 | 占用指挥上限的数量 |
| 护甲 | 使用主文档五类护甲 |
| 科技 | T0–T3 |

### 2.2 计算规则

- 表中的伤害是护甲倍率前的基础伤害。
- 伤害结算采用主文档四伤害、五护甲表。
- 多弹丸单位注明弹丸数量；范围伤害注明半径。
- 不设置随机暴击、随机未命中和随机伤害浮动。
- 范围伤害可采用固定中心衰减，但衰减曲线必须在数据表中公开。
- 移动速度、转向和加减速分开记录；灰盒阶段先统一加速度，避免隐藏操作差异。
- 生产时间受低电力影响，技能冷却不因低电力倒退。

### 2.3 首轮数值调整规则

一次测试版本只调整一个主要方向：

- 成本与生产时间。
- 生存与机动。
- 输出与射程。
- 技能持续时间与冷却。

不得同时提高一个单位的伤害、生命和速度来“补强阵营”。

### 3.4 电力边界测试

标准开局的一座发电厂提供 100 电力：

- 精炼厂和兵营后剩余 50。
- 再建战车工厂后供需恰好为 0。
- 再建雷达站会进入低电力，必须提前补电厂。
- UI 在放置雷达站前显示建成后的 `-50` 差额。

该开局让玩家在第一次科技攀升前遇到一次可理解的电力决策，而不是开局立刻被惩罚。

### 4.3 同盟使用边界

- 守卫兵能反甲和防空，但低移动与低对步输出使其不能单独守全图。
- 鸢尾部署提高阵地效率，但追击时必须解除部署。
- 光棱适合攻击密集高价值目标，不应对少量快速侦察单位拥有同等效率。
- 幻影提供伏击和区域封锁，不提供比鸢尾更高的持续正面交换。
- 寒霜负责反建筑与反固定阵地，不承担持续制空。

### 5.3 赤潮使用边界

- 雪暴能吸收正面火力，但部署不增加输出，不能靠原地驻垒消灭所有敌人。
- 雷霆适合惩罚密集阵地，固定落点让对手可以撤离和分散。
- 磁暴坦克依赖近距离和电网支援，不能替代雷霆的远程职责。
- 天启是推进核心，但其自卫防空不能取代自行高炮。
- 基洛夫的价值来自迫使对手调动防空，不应在无防空时直接摧毁全部基地。

## 6. 经济与采集原型

### 6.1 矿车基线

| 项目 | 同盟 | 赤潮 |
|---|---:|---:|
| 单车容量 | 1000 | 1000 |
| 主矿目标往返周期 | 30 秒 | 34.5 秒 |
| 自然分矿目标往返周期 | 45 秒 | 51.75 秒 |
| 受袭警报 | 有 | 有 |
| 自动续采 | 有 | 有 |
| 特殊能力 | 3 秒紧急迷彩 | 自卫武器 |

主矿单车理论收入用于建立经济曲线，不作为玩家必须达到的操作指标。路径受阻、交战和矿区争夺会降低实际收入。

### 6.2 首轮经济观察点

- 单矿能否支持基础防御与持续主战生产，但不能同时无代价速攀全部科技。
- 第二矿区是否显著提高选择空间，而非只让领先方更快滚雪球。
- 一辆矿车损失是否可恢复，连续两辆以上损失是否形成真实经济压力。
- 矿车自动寻路是否优于手动逐车管理；若手动始终显著更优，应先修路径与采集逻辑。
- 主矿枯竭前，玩家是否已有明确理由争夺第三矿区。

### 6.3 禁止的经济修正

- 不给 AI 隐形的额外采矿倍率。
- 不用动态提高矿车产量来强行缩短对局。
- 不让建筑链接提高精炼厂收入。
- 不通过击杀单位直接获得资金，避免战斗与经济双重滚雪球。

## 7. 垂直切片专精参数

垂直切片只启用同盟“时空机动”和赤潮“装甲突击”。其余专精仍保留在主文档，不进入本轮平衡样本。

主动技能统一在成功施放时扣除资金；取消、目标非法或施放中断不扣资金。持续时间在效果实际生效后开始计算，冷却则从施放开始时计算。

### 7.1 同盟：时空机动

| 项目 | 参数 |
|---|---|
| 被动 | 超时空军团兵与超时空传送仪冷却缩短 15% |
| 单位模块 | 轮式装甲车卸载速度提高 30%，不改变生命与成本 |
| T2 主动：战术召回 | 选择最多 5 个己方普通地面单位，施放 3 秒后传送至己方建造厂安全出口 |
| 战术召回成本 | 300 资金 |
| 战术召回冷却 | 150 秒，从施放开始时计算 |
| 战术召回限制 | 不能召回矿车、基地车、英雄、终极单位；目标被摧毁则该单位不传送 |
| 战术召回反制 | 施放期间目标和目的地均显示标记；击毁目标或迫使玩家取消 |
| T3 主动：时间锚点 | 半径 5 区域持续 10 秒，己方单位免疫敌方传送、心灵控制和时空减速 |
| 时间锚点成本 | 500 资金 |
| 时间锚点冷却 | 180 秒 |
| 时间锚点限制 | 不提供伤害、生命或移动增益；离开区域立即失效 |

战术召回中断规则：

- 玩家主动取消不扣资金，进入 20 秒冷却。
- 对应科技建筑被摧毁时施放中断，进入 20 秒冷却。
- 已完成传送后不能通过摧毁建筑逆转。
- 重建建筑不清空冷却。

### 7.2 赤潮：装甲突击

| 项目 | 参数 |
|---|---|
| 被动 | 重型车辆转向速度提高 20% |
| 单位模块 | 雪暴坦克可花 150 资金安装反应装甲：+150 生命、-10% 移动速度 |
| T2 主动：过载突击 | 半径 4 内己方车辆速度 +25%、转向 +15%，受到伤害 +15%，持续 10 秒 |
| 过载突击成本 | 250 资金 |
| 过载突击冷却 | 100 秒 |
| 过载突击限制 | 不叠加，不作用于飞机、矿车和终极单位 |
| 过载突击反制 | 启动有明显声光效果；利用减速、炮兵和侧后攻击惩罚深入 |
| T3 主动：战场维修区 | 放置一个 400 生命的维修信标，半径 4，持续 12 秒 |
| 维修区成本 | 500 资金 |
| 维修区冷却 | 180 秒 |
| 维修区效果 | 最近 2 秒未开火的车辆每秒恢复最大生命 2% |
| 维修区反制 | 信标可被攻击和 EMP 瘫痪；持续开火单位不获得维修 |

### 7.3 技能验收重点

- 召回主要用于保存昂贵部队和调整防线，不应成为无成本侦察或矿车经济技能。
- 时间锚点只反制时空与控制，不是通用无敌区域。
- 过载同时提高收益和风险，不能只在追击时永远正确。
- 维修区鼓励撤退与轮换，不允许主战场站桩输出同时高速回血。
- 所有技能的音效、图标和范围提示在关闭最终特效后仍可读。

## 9. 灰盒地图：“裂谷前线”

### 9.2 尺寸与对称

- 逻辑尺寸：160×160 格，可按引擎实际地图格式等比转换。

### 9.4 资源分布

| 区域 | 数量 | 单区资源 | 采集规则 |
|---|---:|---:|---|
| 主矿 A | 每玩家 1（由两片相连矿簇组成） | 40000（两片合计） | 安全、标准效率 |
| 自然分矿 B | 每玩家 1 | 35000 | 距主基地较近，有一个防守方向 |
| 侧翼第三矿 C | 每玩家 1 | 30000 | 更靠近中线，运输线暴露 |

### 9.5 路径与视野指标

- 主基地可用建设区至少约 24×24 格。
- 主通道有效宽度 8–12 格，侧翼通道 4–6 格。
- 每个主基地至少两条独立地面出口，不能通过单个炮塔或一段城墙完全封死。
- 侦察车到敌方外围主路的目标时间为 35–50 秒。
- 主矿矿车目标往返 30 秒，自然分矿约 45 秒；赤潮按单位差异另测。
- 中央富矿不能从出生区直接受到 T1 坦克攻击。
- T2 炮兵在自然分矿后方不能直接覆盖敌方主基地超级武器区域。
- 两侧空投路线的飞行时间与防空暴露面积应基本一致。

### 9.6 灰盒阶段关闭的内容

- 不放置中立科技建筑。
- 不放置可破坏桥梁；桥梁先作为永久地形验证侧翼。
- 不加入磁暴、矿脉喷涌或时空乱流。
- 不做最终地表贴图；用颜色和网格标记射程、建造区与矿区。
- 不用装饰物阻塞路径，所有碰撞必须与灰盒视觉一致。

- 版本、地图、阵营、专精、玩家水平和结果。
